Utiliser Musicband Toolbox

Choisissez une rubrique. En haut de chaque page, Instructions rappelle les premières étapes.

Contacts

Retrouvez les personnes et les lieux dans votre carnet. Tapez un nom ou un lieu dans Rechercher : la liste se met à jour toute seule.

Cliquez sur un nom pour ouvrir sa fiche. Colonnes affichées permet de choisir les informations visibles dans le tableau.

Si les boutons sont disponibles, utilisez Nouveau contact pour ajouter une personne ou Modifier pour corriger sa fiche. Cliquez sur Enregistrer pour garder les changements, ou Annuler pour revenir sans les garder.

Concerts

Les concerts à venir et les concerts passés sont présentés dans deux tableaux. Ceux qui n’ont pas de date connue restent dans Dates à préciser.

Tapez dans Rechercher pour retrouver un concert. Cliquez sur son nom pour lire les détails. Colonnes affichées permet de choisir les informations du tableau.

Pour créer ou modifier un concert, utilisez les boutons proposés. Renseignez le nom, la date, le lieu et les informations utiles. Choisissez le contact lié au concert, ou Nouveau client pour en ajouter un sur place. Cliquez sur Enregistrer pour garder la fiche.

Dans la fiche du concert, choisissez une setlist dans la liste puis cliquez sur Associer la setlist au concert. Dissocier retire le lien sans supprimer la setlist. Une setlist liée ne peut pas être supprimée ; pour la réutiliser ailleurs, faites-en une copie sans concert associé.

Devis / Factures

Choisissez Devis ou Facture, puis le client et le concert. Si le client n’existe pas encore, utilisez Nouveau client sans quitter la page.

Le nom et l’adresse viennent de la fiche du client. La date de prestation, la durée, le montant et le mode de règlement viennent du concert. Pour corriger ces informations, modifiez la fiche concernée puis enregistrez à nouveau le document.

Au premier enregistrement, un numéro est donné automatiquement, par exemple Devis 2026-01 ou Facture 2026-01. Chaque type a sa propre suite de numéros pour l’année en cours. Le numéro reste le même lors des modifications.

Le document commence en Préparation. Vérifiez les informations, puis utilisez Valider. Si une correction est nécessaire, remettez-le en Préparation. La création du PDF et l’envoi au client ne sont pas encore disponibles.

Setlist · les morceaux du concert

Choisissez une setlist, puis une variante : c’est une autre version de la même liste. Vérifiez l’ordre des morceaux et la durée totale.

Activez le mode édition pour changer la liste. Déplacez les morceaux avec la poignée ou les flèches ↑ et ↓. Les boutons → Rappel et → Set déplacent un morceau entre la partie principale et le rappel.

Afficher les morceaux non sélectionnés ouvre la réserve. Le bouton + ajoute un morceau ; le bouton − le retire et le remet dans la réserve, y compris s’il était dans le rappel. Certains morceaux restent groupés ou à une place imposée.

Enregistrer crée une nouvelle version avec la date et votre nom. Les versions précédentes restent disponibles. Rétablir la variante annule les changements non enregistrés. Enregistrez avant de changer de liste ou de quitter la page.

Pour emporter la liste, choisissez Export Tempo, Export SACEM, Export Excel ou Imprimer. L’export SACEM contient le lieu du concert, les titres et les artistes, sans séparer le rappel. Il n’est pas envoyé à la SACEM. Les exports reprennent la liste affichée, même si vos derniers changements ne sont pas encore enregistrés.

Sur iPhone, utilisez les options de partage du navigateur pour garder le fichier dans Fichiers.

Sound · XR18 · les réglages du son

Ouvrez un fichier de scène .scn ou une scène déjà conservée. Une scène contient les réglages de la console. Sur iPhone, si le fichier est grisé, faites-en une copie et changez la fin de son nom en .txt.

Choisissez la piste et lancez l’analyse sans IA pour lire ses réglages. Choisissez ensuite l’instrument, décrivez le problème entendu et cliquez sur Construire les essais sans IA.

Essayez les réglages proposés sur la console, un changement à la fois, puis écoutez le résultat. La page ne change pas les réglages de la console à votre place.

Avec Noter le résultat après écoute, indiquez si le son est amélioré, inchangé ou dégradé, puis enregistrez votre retour.

Le menu Actions permet d’ouvrir le rapport PDF. Les autres exports permettent de garder les réglages et les conseils dans un fichier. Sur iPhone, utilisez Partager pour l’enregistrer dans Fichiers.

Gardez vos fichiers d’origine : seules les trois scènes les plus récentes sont conservées sur le site. Enregistrez les rapports utiles avant de quitter la page.

Se déplacer et se connecter

Le menu général permet de revenir à l’accueil, de changer de module ou de se déconnecter. Si votre connexion a expiré, reconnectez-vous. Pensez à enregistrer vos changements avant de quitter une page.

Cliquez de nouveau sur ? pour fermer ce guide. Chaque rubrique peut aussi être repliée.

Instructions
  1. Choisir une setlist et une version, puis vérifier les morceaux et les durées.
  2. Activer le mode édition pour déplacer, ajouter ou retirer des morceaux.
  3. Cliquer sur Enregistrer pour garder une nouvelle version datée à votre nom.
  4. Exporter la liste courante avec Tempo, SACEM, Excel ou Imprimer.
